# Zielgewichte im Papierhandel

DepotSchlopf zeigt Topfwert und aktuelles Gewicht je Position. Lässt ein Berater eine Position im Vorschlag aus, ergänzt DepotSchlopf ihr aktuelles Gewicht. Ein ausdrücklich angegebenes Gewicht von null bedeutet Verkauf. Die bestehenden Bestandsgrenzen gelten auch für ergänzte Positionen.
