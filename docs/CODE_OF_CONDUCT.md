# Umgang miteinander

Für Issues, Pull Requests und alle anderen Projektbereiche gelten diese Regeln für alle Beteiligten, einschließlich des Inhabers:

- Begegne anderen respektvoll und beziehe Kritik auf die Sache.
- Beschreibe Fehler und Meinungsverschiedenheiten konkret.
- Unterlasse Beleidigungen, Belästigung, Drohungen, diskriminierende Angriffe sowie unerwünschte sexualisierte Inhalte.
- Veröffentliche keine privaten Informationen anderer Personen, auch keine Depot- oder Kontodaten.
- Gib keine Kauf- oder Verkaufsempfehlungen an andere. Dieses Projekt ist keine Anlageberatung.

## Meldungen

Offene Probleme über ein [GitHub-Issue](https://github.com/Funcry241/DepotSchlopf/issues/new). Wer Vertraulichkeit braucht, bittet dort neutral um einen privaten Kontakt. Für Verstöße gegen GitHubs Regeln gibt es die [GitHub-Meldewege](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).

Der Inhaber kann um Klärung bitten, verwarnen, Inhalte moderieren oder die Beteiligung einschränken. Eine Antwortfrist ist nicht zugesagt.
