# Risiko- und Haftungshinweis

DepotSchlopf ist ein **experimentelles Privatprojekt**. Es ist **keine Anlageberatung**, keine Finanzdienstleistung, keine Vermögensverwaltung und keine Steuerberatung.

- Wertpapiere können an Wert verlieren, bis hin zum **Totalverlust** des eingesetzten Geldes. Das gilt auch dann, wenn alle Grenzen des Regelwerks greifen.
- Vergangene Ergebnisse, Backtests und Papierhandel sagen nichts Verlässliches über die Zukunft.
- KI-Modelle (Claude, GPT) irren sich, erfinden Fakten und ändern ihr Verhalten mit neuen Versionen. Das Regelwerk begrenzt den Schaden, verhindert aber keine schlechten Entscheidungen innerhalb der Grenzen.
- Software kann Fehler enthalten. Broker-Schnittstellen, Kursquellen und KI-Anbieter können ausfallen oder sich ändern.
- Wer den Code nutzt, handelt auf eigene Verantwortung und eigenes Risiko. Die MIT-Lizenz schließt jede Gewährleistung und Haftung aus, soweit gesetzlich zulässig.

Grundregel des Projekts: **Nur Geld einsetzen, dessen Totalverlust dich nicht trifft.** Erst Papierhandel, dann kleine Beträge.

Steuern: Wer über einen ausländischen Broker handelt, muss Kapitalerträge selbst erklären. Hinweise stehen im Architekturentwurf. Im Zweifel eine Steuerberatung fragen.
